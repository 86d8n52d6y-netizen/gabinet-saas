# Gabinet – wersja SaaS (prywatne)

Aplikacja dla lekarzy dentystów: opisy NFZ i prywatne, zarobki, Kalendarz – z kontami i synchronizacją (licencje i płatności odłożone – decyzja 9).
Stos: Next.js 16, TypeScript, PostgreSQL 16 (RLS), Docker. Docelowo Hetzner (dopiero po testach i zgodzie).
